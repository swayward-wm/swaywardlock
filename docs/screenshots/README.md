# README screenshots

- `ring.png`: an idle glowing ring with an oversized clock and date over a blurred wallpaper.
- `widgets.png`: a hyprlock-style composition with an oversized clock, date and password field
  over the same wallpaper, sharp and without background colour processing.

Captured on 2026-10-22 from real swaywardlock `--preview` windows floating on swayward.
Each border-free window was 1280×720 logical pixels at output scale 1.5; the content crop is
1920×1080 pixels. These are rendered previews, not mock-ups or authentication demonstrations:
preview mode never locks the session or starts PAM.

Both compositions use a fixed copy of the maintainer's current wallpaper, not a live desktop
capture. The screenshot-specific layouts enlarge the text and widgets for readability in the
README; they are not the unmodified example configs. The ring is idle, not mid-typing.

The captured images are shipped with the documentation so the installed README's image links
work too. The original wallpaper is not distributed as a separate asset.
